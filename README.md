# Magic Weather ✨

Навчальний проєкт з JavaScript для роботи з зовнішніми бібліотеками та API.  
Проєкт поєднує:

- роботу з **Open-Meteo API** (геокодинг + прогноз погоди),
- використання **сторонніх бібліотек**: Axios, jQuery, GSAP,
- організацію коду в окремих гілках репозиторію.

---

## 🔧 Функціонал проєкту

- Користувач вводить назву міста (наприклад, _Шостка_).
- Через **geocoding API** отримуються координати міста:
  - `https://geocoding-api.open-meteo.com/v1/search`
- За координатами виконується запит до **forecast API**:
  - `https://api.open-meteo.com/v1/forecast`
- На сторінці відображаються **картки з прогнозом погоди** (дата, мін/макс температура, код погоди).
- Для анімацій використаний **GSAP** (в окремій гілці).

---

## 🌿 Гілки репозиторію

### 1. `js-external-libs` (базова)

- Базовий робочий варіант застосунку погоди.
- Використовується `fetch` для роботи з API.
- Чистий JavaScript (без сторонніх бібліотек для DOM).
- Реалізовано:
  - пошук міста,
  - запит погоди,
  - відмалювання карток погоди.

### 2. `js-external-libs-axios`
